Please Close Door


Description：
1.The power door is open.


Troubleshooting：
1. Close the power door. Press MAIN -> NEXT PAGE -> F6 to enter the IO input page. Check the input of "Power Door Close" and "Power Door Close #2";


2. If the input does not work, use the following method to troubleshoot:
Note: Disconnect the existing wiring shown in the following figure. Use a conductor to connect the input to HCOM and then disconnect it. Check if the corresponding indicator changes in the process.


3. If not, the input is broken. The input needs to be redefined; If the indicator is normal, the outer circuit fails. Check the circuit and switch.
