The outside room temperature is abnormal


Description：
1. The data detected by the external room temperature sensor is out of the set range (0~100 degrees Celsius temperature difference).


Troubleshooting：
1. Shorten the last temperature to see if the alarm is eliminated. If it is not eliminated, please contact the after-sales.


2. Check the wiring of the external room temperature sensor to see if there is disconnection, reverse connection, etc.
