window name：Mold

1.Input and save mold parameters:

1.1 Save: Save running parameters of the current mold. First enter the mold’s name (material and color are optional). Select Save on corresponding lines to save them

1.2 Input: Recover the running parameters of the mold in the line onto the operation panel.

1.3 Delete: Delete the line.

1.4 Export: Copy the parameters in the line to a flash disk.

1.5 Import: Copy one mold’s parameters from a flash disk to a specific line. If there are parameters saved in the line, they will be deleted and replaced.


Export All: Copy all mold parameters saved on the panel to a flash disk. Import All: Import all mold parameters in a flash disk to the panel and delete all existing parameters on the panel.
Note: To export a file, you need to name the file. The name must be different from that of any file in the flash disk. Otherwise, the new file will replace the existing one with the same name.
