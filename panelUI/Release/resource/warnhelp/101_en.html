window name：Product Alarm

1.Auto Alarm: It need to be enabled. When the "Auto Alarm Number" in F3 is reached, it is enabled automatically.


2.Injection Monitor: If it is set to +a and b-, a and b define the deviation range of the injection position that auto monitoring allows. When injection completes, if the difference between the injection position and preset position exceeds the range, the alarm "Injection Monitoring Failure" will be made. A small range can ensure a low defect rate but also trigger too many alarms. Therefore, you should set a proper range.


3.The up limit of each alarm timer is generated when auto alarm is enabled and does not need to be entered manually.
