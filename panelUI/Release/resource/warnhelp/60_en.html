window name：Temp

1.Heating status：

1.1 Gray: Heater is off；

1.2 Blue: Heater is on but this section temp is off；

1.3 Orange: Heating starts and the actual temperature exceeds the PID control range；

1.4 Yellow: Heating starts and the actual temperature is within the PID control range；

1.5 Red: The temperature is abnormal；


2.Temp display：

2.1 When 999 or 777 is displayed, the temperature sensor cable is broken or reversely connected.

2.2 When the field cannot be entered, the field is disabled.


3.3 Use the percentage heating mode to heat the first section. The temperature control buffer of the first section must be set to 0.


4.Heater Warm Time: When each section’s actual temperature reaches the effective temperature, the timer starts. Injection, charging, purging and suck-back can only be performed after the time expires; the effective temperature = preset temperature – 5 centigrade.
