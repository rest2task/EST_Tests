Inject Cushion Error


Description：
1.The injection end position is beyond the maximum error allowed by Injection Monitor.


Troubleshooting：
1.Check if there is material shortage or spilth;


2.Check if the nozzle is blocked;


3.Check if auto alarm Injection Monitor is set too small;


4.If inject #3 is monitored, enter I/O interface to check Inject #3 and if the monitor switch of inject #3 is damaged.
