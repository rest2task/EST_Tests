Core Pull End Error


Description：
1.Clamp closing process:：
1）Core Protection is enabled: The core adv end or return end trigger switch in faulty;
2）Disable Core Protection is disabled: The core adv end trigger switch is faulty.


2.Before injection:
1）Core Protection is enabled: The core adv end trigger switch is faulty;


3.Before ejection:
1）The core return end trigger switch is faulty or the ejector return mark is faulty;


4.Eject during the clamp opening process:
1）The core return end trigger switch is faulty or the ejector return mark is faulty;


Troubleshooting：
1.Check if the input of core adv end or return end works;
Note: See page 3 for the checking method.
