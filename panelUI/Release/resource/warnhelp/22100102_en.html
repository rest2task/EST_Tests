C.P. Active Pos Error


Description：
1.When core protection is set to 1, the core moves before the clamp opens. The reading of the clamp opening/closing scale exceeds the alarming range.


Troubleshooting：
1.Check input Clamp Close End on the I/O interface and if the stroke switch of Clamp Close End is damaged;
Note: See page 3 for the checking method.


2.Check parameters relating to the core movement position and effective clamp opening area.
Note: 0< core movement position - effective clamp opening area < current reading of the clamp opening/closing scale < core movement position + effective clamp opening area


3.Adjust the clamp opening/closing flow properly.
