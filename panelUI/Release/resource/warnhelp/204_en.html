window name：IO Redefine

1.Redefine: Inputs and outputs must be numbered top down. If a line is blank, the definition of all the following lines is invalid. Press Save to save the inputs.


2.Number Input and Output: Number inputs and outputs on the main board of the computer;


3.Define Input and Output: The definition of a line is only displayed after the input and output are numbered. Select the function needed from the pull-down menu. Press left and right arrows on the panel to turn to another page.
