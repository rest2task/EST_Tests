window name：Servo Help

1.You can observe running status of every servo pump on this page. It is very convenient to observe the configuration of pumps during this movement in the multi-pump system.


2.Communication Test:
2.1When "Packet Loss Rate %" is orange, it indicates that many packets are lost. Check the communication wire.

2.2 If the value is negative and the box is black, two or more drives have the same number. If the communication is sound, IMM will enter the motor parameter self-learning step.


3.Self-learning step: (the motor must be switched off)

3.1 Choose the number of the self-learning drive. Reset parameters of the drive.

3.2 Choose the motor's model number and set the maximum rotate speed.

3.3 Open the safety valve of the oil circuit to prevent high-pressure oil from being generated by forward rotation of the motor during self-learning.

3.4 Select Static or Dynamic and start self-learning.

3.5 If an alarm is prompted during self-learning, the self-learning fails. Re-start self-learning after the problem is solved; After self-learning succeeds, the system will prompt "Control Mode Is Changed to EST Control". After you press ENT, the system will enter serve debugging.


4.Servo debugging steps:

4.1 Change the control mode to “EST Control”. Do not forget to change it on slave pumps in a multi-pump system. Switch the motor on.

4.2 Set the pressure and flow of the nozzle return process. Observe running parameters below.

4.3The multi-pump system is tested through the charging movement. Start screw heating. Commission charging pumps one by one to see if the rotate speed of the screw is normal.

4.4If the rotate direction of a motor is wrong, change the value of the rotate direction on the upper right corner to 1.


5.Self-learning Troubleshooting:

5.1ERR43:

a）Check motor parameters of the drive in F1 group. F1-00 to F1-05 are motor's power, rated voltage, current, frequency and rotate speed. If any parameter is wrong, manually modify it or re-select the motor model on the panel;

b）check if the motor's encoder is well connected and if the PG card is normal;

c）check if the motor's oil pump is jammed;

5.2“ERR2/3/4” and other over-current fault: Check if the drive's input and output are short-circuit. Check if the motor's three-phase winding and cable are power-to-ground or mutual short-circuit.


6.ERR10 drive overload during commissioning:

6.1 Check the pressure. If it exceeds the normal value, check the pressure sensor;

6.2 check the motor's oil pump matches the motor;

6.3 check if the oil pump is jammed;

6.4 check if the drive is too small.


7.Pressure Vibration: Adjust 'High speed gain/low speed gain' on the right side.


8.See Servo Help for more failure troubleshooting
