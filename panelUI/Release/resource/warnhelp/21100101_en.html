Eject Position Error


Description：
1.The ejector does not return to the effective position.


Troubleshooting：
1.Enter the ejector parameter page and set Effective Eject Return Area and Eject End Position properly;


2.Enter I/O interface to ensure input Ejector Ret End and if the ejector return end proximity switch is damaged;


3.If ejector protection is enabled, enter I/O interface to check input Ejector Protection and if the ejector protection switch is damaged.
