Waiting Robot


Description：
1.The robot is set to General:
a).Input Robot is not triggered before the clamp is closed.


2.The robot is set to VDE:
a).Input Close Safety is not triggered before the clamp is closed.


3.Robot is set to VDE and input Manual Robot is not triggered:
a).Core is pushed forward and input Core ADV Safety is not triggered;
b).Core returns and input Core RET Safety is not triggered;
c).Ejector is pushed forward and input Ejector ADV Safety is not triggered;
d).Ejector returns and input Ejector RET Safety is not triggered;
e).Input Cycle Start is not triggered before the next semi-auto, time (or electric eye) cycle starts.
