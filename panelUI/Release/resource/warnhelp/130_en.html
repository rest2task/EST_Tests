window name：IO In

1.Function and Status:

1.1 The function of each input is described on the right side of the number and its status is indicated by the dot on the left. When the dot turns green, the input is effective.


1.2 Where the hardware of an input is broken, you can replace the input with a spare input in "IO Redefine". Notably, you need to reconnect the IO terminal on the PLC accordingly.
