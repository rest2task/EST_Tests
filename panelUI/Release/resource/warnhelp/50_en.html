window name：Core

1.Action Position: The core starts when the set clamp opening/closing position is reached. Core action position in the clamp opening process:


2.1 When the value is 0, the core starts before the clamp opens;

2.2 When the value is between 0 and the difference between the opening end position and the effective area, the core starts in the clamp opening process;

2.3 When the value is larger than the difference, the core starts after the clamp opens;


3.Core action position in the clamp closing process:


3.1 When the value is 0, the core starts after the clamp is closed;

3.2 0<<When the value is between 0 and the difference between the opening end position and the effective area, the core starts during the clamp closing process；

3.3 >When the value is larger than the difference, the core starts before the clamp is closed;
