Hopper Empty


Description：
1.The entire charging process exceeds the maximum charging alarm time.


Troubleshooting：
1.Check if there is material in the hopper;


2.If manual charging is performed, select Alarm -> F3 PAR to modify Charging Alarm Time;
Note: Set Auto Alarm On Cycle Number to 0 and disable Auto Alarm.


3. If the alarm is given during automatic operation, select Alarm -> F2 Alarm to modify Charging Alarm Time.
