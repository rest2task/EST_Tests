window name：Temp Para1

1. Buffer: For instance, if the preset temperature is 200 centigrade and the buffer is 30, heating will be stopped when the actual temperature is equal to or larger than 170 centigrade.


2. When the buffer is 0, the corresponding temperature section is disabled.


3. When the buffer is larger than 1, the buffer self-tunes the heating mode; For example, the preset value is 200 centigrade and the buffer is 30, the initial actual temperature reaches 205 centigrade and then starts to fall, then the buffer will be set to 35. If the temperature only reaches 190 centigrade, the buffer will be set to 20.


4. If the buffer is 1, the heating mode in the buffer area is fixed; the buffer for the first and last section is the Temp Control Buffer in PAR2 and that for the middle sections is Temp Control Buffer *2;


5. Temperature control x coefficient, internal control coefficient, irrelevant to adjustment.
