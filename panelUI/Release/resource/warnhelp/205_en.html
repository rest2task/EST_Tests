window name：Lubrication

1.There are three independent lubrication system: Lub 1, 2 and 3. Lub 1 is used by default.


2.Lub Mode: There are three lubrication modes: 1, 2 and 3.

2.1 Enter 0 to use the time lubrication mode: Single lubrication is performed according to Auto Lub Time.


2.2 To enter 1, the pressure detecting relay should be installed at the outlet of the lubrication pump: Lubrication starts, "Auto Lub Time" immediately detects the input terminal of "Lub Detect". 1 is invalid, alarm; 2 is valid, check if "Auto Lub Total Time" expires. If yes, stop lubrication. If not, continue lubrication. When "Auto Lub Delay Time" expires, check if the total time expires. If yes, stop lubrication; if not, start the second lubrication cycle.


2.3 To enter 2, the pressure detecting relay should be installed at the end of the lubricant circuit: Lubrication starts. If "Auto Lub Time" expires first, perform step 2.2; if "Lub Detect" becomes valid first, check if the total time expires. When it expires, stop lubrication. If not, continue lubrication until the lubrication delay time expires. Check if the total time expires again. If yes, stop lubrication. If not, start the second lubrication cycle


3.Auto Lub Count: It is the number of cycle counts before lubrication is started.
