window name：Machine Config

1.Code: Each code has 16 functions. Each function code corresponds to the following hexadecimal numbers: 1, 2, 4, 8, 10, 20, 40, 80, 100, 200, 400, 800, 1000, 2000, 4000, and 8000. When one code has several functions, their hexadecimal numbers will be added and entered into the corresponding code column. When you want to add a function, you can add the function's code into the corresponding code column to prevent existing functions from being deleted.


2.Machine Type: Ordinary and servo machine, it must be selected properly.


3.RPM Holes: Enter the number of actual RPM holes. The charge page will show the screw's rotate speed.


4.You need to enter correct modification code to modify each function and code.


5.System Press Limit: Pressures of all movements are limited by the parameter.


6.Config and PRM backup and recovery: Select Write to copy configuration codes and parameters into a flash disk. Select Read to copy the codes and parameters to another computer. The function can be used to commission same models or replace the host
